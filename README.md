## 🚧 Projeto em destaque

### [POOBank — Finance CLI](https://github.com/DEVkaionasci/Finance_CLI)

Meu primeiro projeto independente em Python, desenvolvido para praticar Programação Orientada a Objetos e conceitos fundamentais de desenvolvimento de software.

**Funcionalidades implementadas:**
- Cadastro e autenticação de contas.
- Armazenamento seguro de senhas com PBKDF2 e salt individual.
- Depósitos e saques.
- Gerenciamento de saldo e limite de crédito.
- Histórico de transações.
- Persistência de dados utilizando arquivos JSON.

**Tecnologias:** Python, POO, JSON e Git.
