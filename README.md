## 🚧 Projeto em destaque

### [POOBank — Finance CLI](https://github.com/DEVkaionasci/Finance_CLI)

Meu primeiro projeto independente em Python, feito para praticar Programação Orientada a Objetos e conceitos fundamentais de desenvolvimento de software.

**Funcionalidades:**
- 🔐 Cadastro e autenticação de contas
- 🧂 Armazenamento seguro de senhas com PBKDF2 e salt individual
- 💸 Depósitos e saques
- 💳 Gerenciamento de saldo e limite de crédito
- 🧾 Histórico de transações
- 💾 Persistência de dados em arquivos JSON

**Tecnologias:** Python • POO • JSON • Git
